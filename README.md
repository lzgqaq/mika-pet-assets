# Misono Mika Animated Pet Assets

一个《碧蓝档案》未花灵感的非官方同人动画宠物素材包，包含 Q 版和像素风两套图集。

## 内容

- `outputs/mika-pet-q/`：Q 版 8×9 spritesheet 与 `pet.json`
- `outputs/mika-pet-pixel/`：像素风 8×9 spritesheet 与 `pet.json`
- `outputs/mika-pet-preview/`：可实时切换风格、动作、速度和手动帧的预览页

每套图集包含 9 个动作，每个动作 8 帧，共 72 帧；图集尺寸为 1536×1872，单帧尺寸为 192×208。动作包含待机、向右跑、向左跑、挥手、跳跃、失败、等待、工作和检查，翅膀带有轻微开合变化。

## 预览

直接打开 `outputs/mika-pet-preview/index.html`，或使用任意静态 HTTP 服务器访问该目录。

## Codex 安装

将以下目录复制到 Codex 的宠物目录：

```text
outputs/mika-pet-q     -> %USERPROFILE%\\.codex\\pets\\misono-mika-q
outputs/mika-pet-pixel -> %USERPROFILE%\\.codex\\pets\\misono-mika-pixel
```
